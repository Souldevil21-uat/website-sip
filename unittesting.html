Unit Testing

This page provides supporting evidence for the Unit Testing project and explains how it demonstrates software verification, assert-based testing, and development discipline.

Project Overview

What It Is

Unit Testing is a project focused on verifying program behavior by testing functions with assert-based checks. Instead of relying only on manual observation, it uses structured tests to confirm whether expected outcomes are correct.

Why It Matters

This project matters because it demonstrates a more disciplined development process. It shows that correctness can be checked systematically and that testing is part of building reliable software.

How It Supports the Objectives

Objective 4

Unit Testing supports Objective 4 because it directly demonstrates testing as part of the software development process, helping verify that program logic behaves as intended.

Objective 3

Unit Testing supports Objective 3 because it checks logic-based functions and confirms whether the program’s decisions and calculations are producing correct results.

Objective 6

Unit Testing supports Objective 6 because it reflects a professional approach to development by emphasizing correctness, verification, and explainable software behavior.

Major Features

Assert-Based Verification

The project uses assert statements to confirm whether functions return correct results.

Pass and Fail Testing

The testing process includes examples of both successful and failing cases to prove the checks are meaningful.

Logic Validation

The project demonstrates how software logic can be verified directly instead of only being guessed from interface behavior.

Project Proof

Supporting Evidence

This project can be supported with screenshots of the test results, assert statements, or application output showing both passing and failing test cases.
