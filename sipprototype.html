Passwordless Security SIP Prototype

This page documents the Senior Innovation Project prototype and explains how it demonstrates problem analysis, software development process, prototyping, testing, and cross-disciplinary technical design.

Project Overview

What the Project Is

This project is a passwordless security prototype designed to reduce password fatigue and improve authentication by combining biometrics, behavioral analysis, and risk-based login evaluation into one concept.

Tools and Technologies Used

The project involved web development, interface design, JavaScript interaction, prototype planning, research, and staged presentation materials. It also required testing, iteration, and refinement based on review and feedback.

Major Features and Ideas

Biometric Login Concept

The prototype presents a system built around modern authentication ideas rather than traditional passwords alone.

Behavioral Analysis

The project explores how login behavior and user patterns could help identify unusual access attempts.

Risk Scoring

A rule-based risk evaluation model helps explain how the system can respond differently based on suspicious activity.

Prototype Presentation

The project includes visual and written materials designed to communicate the solution clearly to reviewers.

Iteration and Refinement

The work changed over time based on project scope, testing needs, and professional feedback.
