Risk Scoring System

This page provides supporting evidence for the Risk Scoring System used in the Passwordless Security SIP Prototype and explains how rule-based evaluation supports the project objectives.

Project Overview

What It Is

The Risk Scoring System is a rule-based model that evaluates login conditions such as time, location, and device context to determine whether a login attempt appears normal or suspicious.

Why It Matters

This system matters because it adds intelligence to the SIP concept. Instead of only allowing or denying access, it introduces a structured way to evaluate behavior and respond differently depending on perceived risk.

How It Supports the Objectives

Objective 3

The Risk Scoring System supports Objective 3 because it uses conditional logic and multiple input factors to generate a calculated result, demonstrating structured algorithmic reasoning.

Objective 4

The Risk Scoring System supports Objective 4 because it was designed as part of solving a real problem in the SIP project and required planning, building, and evaluation as part of the prototype process.

Objective 5

The Risk Scoring System supports Objective 5 because it demonstrates cross-disciplinary technical thinking that combines interface design, security concepts, and interactive logic in one prototype.

Major Features

Multiple Input Factors

The system evaluates more than one condition instead of making decisions based on a single login event.

Rule-Based Evaluation

It uses clear logic rules to raise or lower concern depending on the situation.

Adaptive Response Concept

The model supports the idea that suspicious activity should trigger different treatment than ordinary behavior.
