Movie Planner

This page provides supporting evidence for the Movie Planner project and explains how it demonstrates application structure, interface logic, and organized software design.

Project Overview

What It Is

Movie Planner is a software project designed to organize movie-related information through an interactive application interface. It uses user input, program logic, and organized data handling to create a usable planning tool.

Why It Matters

This project matters because it demonstrates software structure and interface design in a way that is different from gameplay programming, adding more breadth to the portfolio.

How It Supports the Objectives

Objective 2

Movie Planner supports Objective 2 because it required a structured software design for handling user input, organizing information, and keeping the application maintainable.

Objective 5

Movie Planner supports Objective 5 because it demonstrates software development in a desktop application environment beyond web and game engine work.

Objective 6

Movie Planner supports Objective 6 because it contributes to a broader professional portfolio and demonstrates the ability to present a complete and organized software project.

Major Features

Interactive Planning Workflow

The project provides a usable flow for entering and working with movie-related information.

Structured Data Handling

Information is managed through organized program logic rather than static display only.

Desktop Application Design

The project adds experience with interface controls and application design in a non-web environment.

Supporting Evidence
