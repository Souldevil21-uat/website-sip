GameManager System

This page provides supporting evidence for the GameManager System used in UATanks and explains how it demonstrates system architecture, gameplay support, and software organization within a complete game project.

Project Overview

What It Is

The GameManager System is a central controller that helps coordinate major parts of the UATanks project. It manages game states, player and AI registration, spawning logic, score handling, and overall game flow. Instead of letting every system operate independently without structure, the GameManager provides one place for shared control and communication.

Why It Matters

This system matters because larger game projects need a central structure to remain stable and organized. The GameManager reduces confusion between systems, helps track important objects in the scene, and makes it easier to manage the full game loop from startup through active play and end conditions.

How It Supports the Objectives

Objective 2

The GameManager System supports Objective 2 because it acts as an architectural backbone for the project. It connects separate gameplay systems such as spawning, score tracking, player control, AI control, and game states into one structured framework.

Objective 4

The GameManager System supports Objective 4 because it was designed as a solution to the problem of managing many moving parts in a game project. It required planning, implementation, testing, and adjustment to ensure the different systems worked together correctly.

Objective 5

The GameManager System supports Objective 5 because it demonstrates development ability in Unity using C#, including object references, game state logic, shared system management, and scripting for a real gameplay environment.

Major Features

Player and AI Registration

The system keeps track of active players, AI controllers, and pawns so other systems can access them when needed.

Game State Control

The GameManager handles transitions between menu states, gameplay, and game over conditions to keep the experience organized.

Spawning and Tracking

The system supports player spawning, AI spawning, and the overall tracking of active entities in the level.
