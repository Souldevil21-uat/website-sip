UATanks

This page serves as supporting evidence for the Game Programming degree objectives by showing how UATanks demonstrates gameplay implementation, systems architecture, algorithms, testing, and development across a complete Unity-based project.

Project Overview

What the Project Is

UATanks is a 3D Unity game project built in C#. The project includes player-controlled tanks, AI-controlled enemy tanks, projectile shooting, health systems, pickups, score systems, spawning, and game flow logic. It was created as part of game programming coursework to demonstrate practical gameplay programming and system integration.

Tools and Technologies Used

This project was built using Unity, C#, and the Unity Editor. Development included scripting gameplay systems, connecting prefabs and components, testing game behavior in-engine, and iterating on mechanics such as AI, combat, spawning, and user interface systems.

How UATanks Supports the Objectives

Objective 1

UATanks supports Objective 1 by showing a completed 3D game project created with common industry tools. The project includes interactive gameplay systems, player control, AI enemies, and a playable structure that demonstrates game implementation on PC using Unity and C#.

Objective 2

UATanks supports Objective 2 by using a structured architecture with separate systems for movement, projectiles, health, AI behavior, spawning, powerups, score tracking, and game state logic. This shows how a complete project can be supported by organized infrastructure rather than one oversized script.

Objective 3

UATanks supports Objective 3 through state-driven AI, spawning systems, collision handling, object references, score logic, and health management. These mechanics rely on gameplay-related logic and algorithmic decision making that can be analyzed and improved through testing.

Objective 4

UATanks supports Objective 4 by showing the full software development process in practice. The project required identifying gameplay problems, designing systems, building them in code, testing them in Unity, and revising them when bugs or design issues appeared.

Objective 5

UATanks supports Objective 5 by demonstrating development skills in Unity and C#, while also showing how game systems can be developed in a professional engine environment with reusable scripts, editor-based workflows, and interactive testing.

Major Features Implemented

Player Tank Controls

The player can move, rotate, and interact with the game world through tank controls, demonstrating core player input and movement programming.

Enemy AI

AI tanks were developed with different behaviors and logic patterns, showing the use of scripted decision making in gameplay.

Projectile Combat

Tanks can fire projectiles, apply damage, and interact with health systems, demonstrating combat logic and object interaction.

Powerups and Score

The project includes pickups and score tracking, which help expand the gameplay loop and reward player interaction.

Game Management Systems

A GameManager and related scripts control flow, spawning, tracking, and other global systems needed for the game to operate consistently.
