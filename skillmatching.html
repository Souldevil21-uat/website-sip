Skill Matching Algorithm

This page provides supporting evidence for the Skill Matching Algorithm used in SkillSwap Hub and explains how the logic behind matching users supports the degree objectives.

Project Overview

What It Is

The Skill Matching Algorithm is the logic used to compare the skills a user already has with the skills they want to learn. It determines whether a meaningful match exists and helps generate useful interactive results in the application.

Why It Matters

This system matters because it is the main functional logic behind SkillSwap Hub. Without it, the project would only be a static interface instead of a meaningful interactive tool.

How It Supports the Objectives

Objective 3

The Skill Matching Algorithm supports Objective 3 because it uses conditional logic and structured comparisons to generate results from user input data.

Objective 4

The Skill Matching Algorithm supports Objective 4 because it was developed as a solution to an interaction problem and had to be designed, implemented, tested, and refined for usefulness.

Objective 5

The Skill Matching Algorithm supports Objective 5 because it demonstrates JavaScript-based front-end logic in a web development environment outside of traditional game engines.

Major Features

User Input Comparison

The algorithm compares different fields of user-entered data to determine possible matches.

Conditional Decision Making

Logic rules decide when a skill match is strong enough to show as a useful result.

Interactive Feedback

The system supports a responsive user experience by changing outputs based on entered information.
