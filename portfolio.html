Portfolio Website

This page documents the portfolio website as a professional presentation project that demonstrates design, organization, communication, and polished delivery of technical work.

Project Overview

What the Project Is

The portfolio website is a professional site designed to present projects, Boards evidence, SIP materials, and contact information in one organized location. It serves as both a technical project and a polished communication tool.

Tools and Technologies Used

The site was built using HTML, CSS, and JavaScript. Development included page design, navigation structure, responsive layout, content organization, and presentation planning.

How the Portfolio Website Supports the Objectives

Objective 2

The portfolio website supports Objective 2 by using organized page structure, navigation systems, and shared styling to support a complete and coherent web project.

Objective 4

The site supports Objective 4 by showing the full process of identifying presentation needs, designing a solution, building it, testing it, and refining it for clarity and usability.

Objective 5

This project supports Objective 5 through front-end development using multiple web technologies and environments outside of engine-based game development.

Objective 6

The portfolio strongly supports Objective 6 by presenting work professionally, organizing technical evidence clearly, and preparing polished materials for external review.

Professional Readiness

Beyond the degree objectives, the site demonstrates readiness for professional presentation by acting as a central hub for academic and technical work.

Major Features Implemented

Multi-Page Navigation

The website uses clear navigation to connect major areas such as Home, SIP, Boards, Projects, and Contact.

Consistent Styling

Shared CSS creates a unified visual design across all pages.

Responsive Layout

The site is structured to display more effectively across different screen sizes.

Project Showcasing

The site gathers multiple projects into one place so they can be reviewed more easily.

Boards Support

The website provides supporting pages and evidence that directly strengthen the Boards presentation requirements.
