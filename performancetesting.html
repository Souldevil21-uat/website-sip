Performance Testing

This page provides supporting evidence for the Performance Testing project and explains how it demonstrates algorithm analysis, timing evaluation, and data-focused programming.

Project Overview

What It Is

Performance Testing is a project focused on measuring how code behaves as input size changes. It involved generating arrays, timing operations, and evaluating how sorting and processing performance changed under different conditions.

Why It Matters

This project matters because it directly demonstrates analytical thinking about efficiency and performance rather than only building visible interface features.

How It Supports the Objectives

Objective 3

Performance Testing supports Objective 3 because it directly measures algorithm behavior and analyzes how runtime changes based on input size and processing work.

Objective 4

Performance Testing supports Objective 4 because it required building a working solution, measuring the results, and verifying that the program behaved correctly under larger data conditions.

Objective 5

Performance Testing supports Objective 5 because it demonstrates technical programming skill in a more analytical and data-focused context, not just user-facing interface work.

Major Features

Array Generation

The project creates arrays of different sizes to test how data volume changes program behavior.

Sorting Evaluation

The program measures sorting behavior to analyze execution time and efficiency.

Timing Analysis

The project records how long operations take, helping evaluate performance trends.
