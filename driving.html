Driving System

This page documents the Unreal Engine driving system project and explains how it supports the Game Programming degree objectives through vehicle movement, input systems, blueprint logic, and interactive 3D gameplay.

Project Overview

What the Project Is

The Driving System project is a 3D Unreal Engine vehicle prototype focused on player input, acceleration, steering, braking, and movement behavior. It demonstrates gameplay programming through blueprint-based systems and real-time interaction in a 3D environment.

Tools and Technologies Used

This project was built in Unreal Engine using blueprint scripting, input mapping, and engine-based testing. Development included implementing player controls, tuning movement behavior, and testing the vehicle system in an interactive environment.

How the Driving System Supports the Objectives

Objective 1

This project supports Objective 1 by implementing a playable 3D experience in Unreal Engine. It demonstrates the use of a common industry tool to create interactive gameplay on a PC platform.

Objective 2

The project supports Objective 2 through the setup of input architecture, movement systems, and gameplay logic needed to support a complete vehicle prototype.

Objective 3

The driving system supports Objective 3 through movement calculations, acceleration control, steering logic, and input-response behavior that rely on algorithmic decision-making and gameplay-related systems.

Objective 4

This project supports Objective 4 by demonstrating the process of identifying control and movement problems, building a driving solution, testing it in-engine, and refining it based on behavior and usability.

Objective 5

The project supports Objective 5 by showing development in Unreal Engine through blueprint systems and editor-based workflows, demonstrating flexibility across multiple development environments.

Major Features Implemented

Acceleration and Braking

The vehicle can increase or decrease speed through player input, demonstrating movement control and responsive gameplay behavior.

Steering

The system includes directional turning using player input, demonstrating navigation and control within a 3D environment.

Input Mapping

The project uses Unreal input systems to connect player actions to vehicle behavior, showing structured control design.

Blueprint Logic

Core gameplay behavior was built through blueprint scripting, showing node-based programming and engine-level design skills.

Testing and Iteration

The project required repeated testing and adjustment of speed, control feel, and turning behavior to improve usability and functionality.
