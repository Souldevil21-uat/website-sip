Boards — Game Programming Objectives

The objective language below follows the current University of Advancing Technology Game Programming degree objectives. Each section lists completed work and explains how that work demonstrates the objective rather than only describing the project.

Objective 1

Implement multiple completed games, including 3D games, using common tools, languages, and software for web, console, PC, or mobile platforms.

UATanks (Unity / C#)

This project demonstrates the objective by showing a completed 3D game prototype built with Unity and C#. The work includes player controls, AI opponents, projectile combat, pickups, and level interaction, which proves the ability to implement a playable game using a common engine, a common programming language, and platform-ready workflows used for PC development.

Driving System (Unreal Engine)

This project meets the objective by implementing a 3D vehicle experience in Unreal Engine using blueprint-driven mechanics and input systems. It demonstrates that multiple game environments and toolsets can be used successfully to create gameplay on a modern engine, which supports the objective's emphasis on multiple completed games and common industry tools.

Objective 2

Design, develop, and implement the architecture and infrastructure needed to support a complete game project.

UATanks (Unity / C#)

UATanks demonstrates this objective by separating core systems into reusable components such as movement, projectiles, health, AI behavior, pickups, and spawning logic. That modular architecture shows an understanding of how to structure code and supporting systems so a complete game project can be expanded, maintained, and tested without collapsing into a single monolithic script.

SIP Website & Prototype

The SIP website and working prototype meet this objective by combining front-end presentation, JavaScript interaction, asset organization, and a staged prototype experience into one coherent system. The project demonstrates how architecture decisions such as page structure, shared styling, navigation, and modular JavaScript help support a complete and explainable interactive experience.

Objective 3

Implement and analyze fundamental data structures and algorithms associated with game applications supporting gameplay mechanics.

UATanks (AI, Spawning, and Combat Logic)

This work supports the objective by using state-driven logic, ordered update behavior, collision handling, and data passed between systems such as projectiles, pawns, and health components. The project shows how gameplay mechanics depend on algorithmic decisions, data flow, and system relationships that can be analyzed and refined for responsiveness and balance.

Passwordless Security SIP Prototype

The SIP prototype demonstrates this objective by implementing a rule-based scoring model that evaluates login time, device type, and location patterns to produce a risk score. Although this is not a traditional game, it still demonstrates algorithm design, threshold evaluation, conditional logic, and adaptive feedback loops similar to the kinds of decision systems used in gameplay and simulation.

Objective 4

Use software development processes to analyze a project problem and to design, build, and test a corresponding software solution.

Passwordless Security SIP Prototype

This project meets the objective by starting with a clearly defined problem—password fatigue and insecure authentication—and then moving through scope revision, prototyping, testing, and iteration based on SME feedback. The final prototype reflects a complete development process: identifying the problem, narrowing the scope, building a functional solution, and testing the output to verify the innovation.

SkillSwap Hub (JavaScript Web App)

SkillSwap Hub demonstrates this objective by taking a matching and interaction problem and translating it into a working web interface backed by client-side logic. The project required planning user flow, organizing features, testing interface behavior, and revising the implementation so the final experience solved the original interaction problem in a clear and usable way.

Objective 5

Demonstrate development skills using multiple programming languages, development environments, and platforms, including advanced and/or experimental topics in game programming.

UATanks + Driving System

Together, these projects demonstrate development across multiple engines, environments, and programming approaches. UATanks uses Unity and C# scripting, while the Driving System uses Unreal Engine and blueprint-driven logic, showing flexibility across development tools and proving an ability to adapt to different production pipelines and technical constraints.

SkillSwap Hub + SIP Website

These web projects demonstrate front-end development skills using HTML, CSS, and JavaScript in a browser-based environment. They show that development skills extend beyond game engines into broader interactive software platforms, which supports the objective's emphasis on multiple languages, environments, and experimental or cross-disciplinary applications.

Objective 6

Establish collaboration, mentorship, and professional leadership skills by working with other disciplines to deliver highly polished and completed projects.

SIP Process, SME Reviews, and Showcase Preparation

The SIP process demonstrates this objective through regular review cycles, scope revision based on expert feedback, and presentation preparation intended for a professional audience. Working through critique, refining documentation, and shaping the prototype around SME guidance shows an ability to collaborate, accept direction, and improve a project through structured professional feedback.

Portfolio Website and Boards Preparation

Building the portfolio site for Boards demonstrates professional leadership by organizing work for external review, presenting evidence clearly, and preparing polished materials that communicate technical ability to faculty and future employers. The process reflects not just coding ability, but also accountability, communication, and the discipline required to complete and present finished work.
