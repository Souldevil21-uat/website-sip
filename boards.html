Objective 1

Create and implement multiple completed game experiences, including 3D games, using widely used tools, programming languages, and software platforms such as web, console, PC, or mobile environments.

UATanks (Unity / C#)

This demonstrates the objective because UATanks is a completed 3D Unity game project that includes player movement, AI enemies, combat, pickups, scoring, and game flow systems, proving the ability to create a playable experience using a common engine and language.

Driving System (Unreal Engine)

This demonstrates the objective because the Driving System shows a second 3D gameplay experience created in Unreal Engine, proving the ability to work in more than one major development environment while still producing interactive results.

SkillSwap Hub

This demonstrates the objective because SkillSwap Hub is an interactive software project built with HTML, CSS, and JavaScript, showing the ability to create a complete digital experience on the web platform using standard development tools.

Passwordless Security SIP Prototype

This demonstrates the objective because the SIP prototype presents a structured and functional interactive system with multiple screens and user flow, showing the ability to build a complete digital product even outside a traditional game engine.

Portfolio Website

This demonstrates the objective because the portfolio website is itself a completed digital product that organizes content, navigation, and project presentation into a usable interactive platform.

UATanks (Unity / C#)

SkillSwap Hub (Matching Logic)

This demonstrates the objective because SkillSwap Hub compares user-entered skills using condition-based logic, showing how algorithmic decision making can power interactive results.
