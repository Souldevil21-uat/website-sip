Boards — Game Programming Objectives

The objective language below follows the current University of Advancing Technology Game Programming degree objectives. Each section lists completed work and explains how that work demonstrates the objective rather than only describing the project.

Each project listed below links to a dedicated subpage that includes additional explanations, screenshots, and supporting evidence to fully demonstrate completion of each objective.

Objective 1

Implement multiple completed games, including 3D games, using common tools, languages, and software for web, console, PC, or mobile platforms.

UATanks (Unity / C#)

UATanks demonstrates this objective by showing a completed 3D game prototype built in Unity with C#. The project includes player movement, combat, AI enemies, pickups, scoring, and game flow systems, which together show the creation of a playable game using common PC game development tools.

Driving System (Unreal Engine)

The Driving System project supports this objective by implementing a 3D vehicle experience in Unreal Engine using blueprint-based logic and modern input systems. It shows that multiple engines and toolsets can be used to create functional gameplay experiences.

SkillSwap Hub

Although SkillSwap Hub is a web project instead of a traditional game, it still demonstrates interactive software implementation using HTML, CSS, and JavaScript. It shows the ability to build a functional digital experience on a different platform using common web tools.

Passwordless Security SIP Prototype

The SIP prototype demonstrates interactive system design and implementation through a structured prototype that models user login, risk analysis, and interface flow. While not a game, it reflects the same technical ability to create complete digital experiences.

Portfolio Website

The portfolio website supports this objective by presenting completed digital work through a structured and functional web platform. It demonstrates the ability to build interactive software artifacts beyond game engines while still using industry-standard tools.

Objective 2

Design, develop, and implement the architecture and infrastructure needed to support a complete game project.

UATanks (Unity / C#)

UATanks demonstrates this objective through organized systems for movement, health, AI, projectiles, spawning, pickups, scoring, and game management. That structure shows how a complete project depends on stable and modular architecture.

Driving System (Unreal Engine)

The Driving System supports this objective through its setup of player input, vehicle behavior, acceleration, steering, and blueprint logic. These connected systems form the infrastructure needed to support a complete vehicle prototype.

SIP Website & Prototype

The SIP website and prototype meet this objective through shared page structure, organized navigation, reusable styling, and interactive JavaScript behavior. The project shows how software architecture supports a clear and complete user experience.

SkillSwap Hub

SkillSwap Hub supports this objective by separating layout, styling, and matching logic into an organized structure. That separation makes the project easier to maintain, test, and extend, which reflects strong architectural planning.

Portfolio Website

The portfolio website demonstrates this objective through consistent navigation, reusable design elements, and page organization that support multiple sections of content inside one complete project framework.

Objective 3

Implement and analyze fundamental data structures and algorithms associated with game applications supporting gameplay mechanics.

UATanks (AI, Spawning, and Combat Logic)

UATanks supports this objective through AI behavior, state-driven logic, projectile interaction, collision checks, spawning, and score handling. These systems depend on gameplay algorithms and structured data relationships.

Driving System (Movement Logic)

The Driving System demonstrates algorithmic thinking through steering calculations, acceleration control, braking behavior, and input-response logic. These are core interactive systems that require step-by-step mechanical reasoning.

SkillSwap Hub (Matching Logic)

SkillSwap Hub supports this objective through conditional checks and comparison logic used to match user-entered skills. This demonstrates structured decision making and practical algorithm implementation in an interactive application.

Passwordless Security SIP Prototype

The SIP prototype supports this objective through rule-based risk scoring that evaluates time, location, and device patterns. That model demonstrates threshold logic and system-driven decision making similar to adaptive mechanics.

Portfolio Website (Navigation and Structure)

The portfolio site supports this objective on a broader software level by using organized navigation and structured page behavior. While simpler than gameplay logic, it still demonstrates how information can be managed through consistent digital structure.

Objective 4

Use software development processes to analyze a project problem and to design, build, and test a corresponding software solution.

Passwordless Security SIP Prototype

This project strongly demonstrates the objective by beginning with a real problem, narrowing the scope, developing a prototype, and improving the solution through review, testing, and iteration.

SkillSwap Hub (JavaScript Web App)

SkillSwap Hub supports this objective by identifying a user interaction problem, designing a solution, building the interface, testing the behavior, and revising the application for clarity and usability.

UATanks

UATanks supports this objective through the repeated design, building, debugging, and refinement of gameplay systems such as AI, movement, projectiles, and powerups. The project reflects the full software development cycle in a game environment.

Driving System

The Driving System demonstrates this objective by identifying movement and control goals, implementing them in Unreal Engine, testing the results in real time, and adjusting the system to improve how the vehicle feels and responds.

Portfolio Website

The portfolio website supports this objective by analyzing the need for professional presentation, designing a complete site, testing navigation and layout behavior, and refining the final result for external review.

UATanks

UATanks demonstrates development in Unity using C#, showing experience with engine scripting, gameplay systems, editor workflows, and object-based game development.

Driving System

The Driving System demonstrates development in Unreal Engine using blueprint logic and engine-based testing, which shows flexibility across a second major development environment.

SkillSwap Hub

SkillSwap Hub demonstrates front-end development using HTML, CSS, and JavaScript in a browser-based environment, expanding technical ability beyond traditional game engines.

SIP Website & Prototype

The SIP prototype supports this objective through cross-disciplinary development that combines web technologies, interface design, technical planning, and experimental security concepts.

Portfolio Website

The portfolio site demonstrates additional web development skills through responsive layout, structured navigation, and polished presentation across multiple pages and devices.

The SIP process demonstrates collaboration through review cycles, mentorship, feedback, scope adjustments, and refinement based on professional guidance.

Portfolio Website

The portfolio website demonstrates professional leadership by organizing work clearly and presenting polished technical evidence for outside review by faculty and future employers.

SkillSwap Hub Presentation

UATanks Development Process
